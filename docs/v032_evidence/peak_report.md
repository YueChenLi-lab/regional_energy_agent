## 稳健性结论

未超过预声明判据，在本次预算、范围及假设下推荐未显示明显敏感（容量差阈值max(1kW、kW_th或kWh,基准容量×1.0%)；NPV差阈值1.0%）。人为处理研究假设，不认定原数据错误，不是校准后的实测。负荷电量本身改变会影响成本和排放，不能把全部差值归因于设备配置改善；仅评价推荐对这些峰值处理假设是否敏感，不判断真实峰值应是多少。

仅对本次声明的研究情景和预设判据有效；没有运行替代楼宇、其他峰值点或多价格/天气年实验。
