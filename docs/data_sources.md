## 当前实际使用的来源

[`energy_agent/data.py`](../energy_agent/data.py) 的演示生成器提供常规电负荷、热负荷、光伏归一化出力、电价、燃气价格、电网排放因子和燃气排放因子。默认种子为 42，起点为 `2025-01-06T00:00:00+08:00`，生成 168 个逐小时区间；固定输入与种子可复现时序。夜间光伏为零，负荷非负，光伏出力限定在 [0, 1]。这些日期仅是演示时轴，不表示对应时段的真实观测。

| 实际 source_id | 覆盖内容 | 类别 |
| --- | --- | --- |
| `demo-series` | 电热负荷与归一化光伏 | synthetic，合成 |
| `demo-market` | 电价、气价与排放因子 | synthetic，演示假设 |
| `demo-equipment` | COP、效率、SOC、设备和安装成本 | synthetic，演示假设 |
| `demo-conditions` | 预算、场地、购电和排放限制 | synthetic，演示假设 |
| `demo-candidates` | 四个有限容量配置 | synthetic，演示假设 |

设备效率、容量候选、设备单价、安装成本、预算、购电上限、场地和排放约束来自 [`energy_agent/demo_config.json`](../energy_agent/demo_config.json) 或用户输入。演示参数不是当地现行参数，不可用于未经校准的投资决策。具体数值、时间范围和处理记录以每次运行导出的任务及来源记录为准。

## 统一来源记录

每份时序数据、设备参数、约束和候选配置都应能关联到来源记录，至少包含：

- source_id 与来源名称；地区和时间范围；无法确认时明确记为“未知”。
- 单位与类别（实测、仿真、合成或明确的其它类别）。
- 使用条件，包括演示限定、授权或适用限制。
- 处理记录，例如生成方法、随机种子、筛选、负荷缩放或格式转换；涉及处理时记录受影响的区间。

用户修改参数后保留原来源并新增或更新对应的输入/处理记录；不能将修改后的假设仍描述为原始实测值。来源元数据是追溯声明，程序不能自动核实其真实性。

## 后续接入步骤

1. 取得可使用的真实样本并核对许可和用途限制，记录来源版本与获取时间。
2. 实际阅读字段说明与文件，确认时间戳、时区、间隔、单位、测点与负荷边界；需要聚合时明确规则。
3. 映射到本项目公开的统一格式。不同外部格式只在取得样本后编写适配器。
4. 检查缺失、重复时间、间隔、非数值/无穷值、负值及异常边界。缺失不自动补零；有必要的插补必须显式说明方法与受影响区间。
5. 用已知样本检验能量守恒和单位换算，再替换演示来源。外部数据接入与模型参数校准是独立验收步骤。
