# 后续开发路线

v0.1 的验收边界是：单节点电热负荷、有限容量候选、确定性运行优化、独立物理校验、可追溯报告、中文演示界面和无模型密钥的完整演示。本页记录后续工作，不代表这些能力已经实现。

## 下一阶段优先的三件事

1. **真实数据与参数校准。** 从 [来源清单](data_sources.md) 中取得有权使用的样本，实际核查文件、单位、时间戳、缺失与授权，完成一个有测试的真实格式适配器；引入经过核实的设备成本、当地价格和排放因子。与合成数据分开标识，验证完整年度输入的时间处理和性能。
2. **模型可信度与决策质量。** 对关键成本、COP、效率、气象和负荷作敏感性分析，扩大但限制候选网格规模；补充独立基准算例与求解器对照。研究可解释的无解诊断，在独立诊断模式下输出缺供量或约束冲突证据；保留初始投资、时段运行费和排放的独立口径。
3. **模型接口与交互验收。** 使用用户自愿配置的服务做真实 LLM 端到端验收，验证结构化解析、非法输出重试、工具白名单及版本变更追溯；补充真实浏览器的界面与导出验证。模型仍只解释与安排工具，所有容量、费用、排放均来自确定性输入和计算。

## 研究扩展，另立范围

- 温度相关 COP、部分负荷效率、电池寿命和衰减、分时碳因子等更细设备与运行模型。
- 供冷、冷热管网、多节点、空间场地约束与可靠性/故障备用。需要新的数据、公式和专门测试，不能将 v0.1 未建模的需求默认为已满足。
- 多年现金流、设备替换、残值、全生命周期排放与多目标规划。先建立明确边界和参数来源，禁止把单周结果直接外推为年度结论。
- 连续容量优化、随机情景和鲁棒规划。只有新的数学模型与验收支持时，才改变“有限候选方案中比较”的结论限定。
- 售电、绿证、碳抵消等政策机制。需明确地区、有效时间、交易规则和可核验数据；不默认给予收益或减排信用。

以上扩展不属于 v0.1 交付，不为了竞赛展示而把未来能力写成现成功能。当前模型适合方法演示、代码验证和研究原型，实际工程决策仍需要真实参数校准与更充分的工程约束。


## v0.2第一阶段完成后

已完成EnergyDetective固定正式档案、NASA同期UTC资源、电侧边界、单位/能量核对、全文件/窗口质量、字段来源、缓存重放、中文导入及可追溯优化报告。真实精确建筑坐标、测点电气回路完整性、Time区间锚点及2017适用电价仍未证实；这些是明确的假设，不因导入成功而消失。

接下来优先：①与数据发布方或建筑方核实计量/时间边界及适用价格和收费范围；②核实屋顶、设备成本与效率并用实测PV校准资源模型，做参数敏感性；③完整年度时间/性能验收和更深入的可解释无解诊断。真实LLM、供热估算、供冷和多节点仍另立范围；瑞丽无文件时维持登记，不编造接入。
