# 后续路线

v0.1：单节点电热合成演示、有限候选运行优化、独立验证、报告及中文UI。
v0.2：EnergyDetective真实电侧导入、质量与追溯、NASA估算PV、许可168小时离线案例。
v0.3本轮：完整2017日历年电侧/Q＋仿真供热研究、NPV现金流和联合容量优化、有限成本—排放扫描、DeepSeek受限动作及可核对解释接口。真实DeepSeek调用需安全配置后单独验收，尚未通过。具体证据见v03_validation。

接下来优先三项：

1. 在本机安全配置DeepSeek，完成限制10次的真实验收，结合真实服务错误与用户澄清反馈调整协议；不以模拟测试代替。
2. 取得瑞丽实际文件、热计量或建筑参数与价格/费用政策，核实Q异常峰值、时间锚点、场地和服务边界，校准供热与PV模型。
3. 增加多气象年、价格/成本不确定性与设备衰减，评估全年求解性能及更完整的前沿；之后再考虑供冷、多节点、故障保障和有来源的设备隐含排放。

不把本轮结果当工程投资决策、全局容量空间的真实最优或零碳认证。没有把一周乘52当年度。
